# Smart Library Management System

## 📚 Project Overview
The Smart Library Management System is a simple project developed in C language to manage library operations efficiently. This system helps in maintaining book records, issuing books, returning books, and managing library details digitally.

## ✨ Features
- Add new books
- Display available books
- Search books
- Issue books
- Return books
- Manage library records
- Simple and user-friendly interface

## 🛠️ Technologies Used
- C Programming Language
- File Handling
- Structures in C

## 🎯 Purpose of the Project
This project is designed to reduce manual work in libraries and make book management easier, faster, and more organized.

## ▶️ How to Run the Program
1. Download or clone the repository
2. Open the project in any C compiler
3. Compile the `library_management.c` file
4. Run the program
